# 2 分钟 Demo 视频脚本

目标：展示 FinSignal-Hy3 是一个可运行的 Hy3 金融分析应用，并且有面向开放式任务的自定义评估方法。

## 录制前准备

```bash
streamlit run app/streamlit_app.py
```

确保本地 `.env` 已配置 `HY3_API_KEY`；若使用在线 Demo，可直接打开 README 中的 Demo 链接。

## 时间轴

### 0:00-0:15 项目定位

画面：README 首页或 Demo 顶部。

旁白：

> 这是 FinSignal-Hy3，一个犀牛鸟开源实战任务个人作品。项目基于混元 Hy3，面向财务学习者、投研实习生和审计辅助人员，输入上市公司连续多年结构化财务数据，输出可核查的财务关注信号。

### 0:15-0:35 输入真实样本

画面：Streamlit 的「选择样本」页，选择一条 READY 样本，例如万华化学 2021-2023；再切换到文本预览。

旁白：

> Demo 支持真实样本、CSV/Excel 上传、表格录入和文本粘贴。这里选择已经结构化的公开年报样本，所有金额已统一为元，来源清单记录在 data/derived/manifest.csv。

### 0:35-0:55 调用 Hy3

画面：点击「运行扫描」，等待结果返回。

旁白：

> 模型调用通过 Hy3 的 OpenAI-compatible 接口完成，API Key 只从本地环境变量读取，不硬编码、不提交仓库。

### 0:55-1:20 展示信号卡片

画面：展示卡片中的严重度、事实依据、计算过程、替代解释、建议核查和结论边界。

旁白：

> 输出不是一句泛泛总结，而是结构化信号卡片。每张卡片要求包含原始数值、期间、公式、替代解释和可核查建议，并明确说明不能据此认定财务造假，也不构成投资建议。

### 1:20-1:45 展示本地校验面板

画面：展示 D1/D2/D3/D7/D8 校验区域和 fact_basis 表格。

旁白：

> 项目重点是评估方法。评估器会检查事实数值、公式结构、证据字段完整性、解释边界和安全合规。批量评测还会计算严重异常漏报率、精确率、加权召回和严重度一致性。

### 1:45-2:00 展示结果材料

画面：快速切到 `docs/report.md`、`data/derived/discriminative_validation.csv`、`data/derived/consistency_validation.csv`。

旁白：

> 评估方法已经做了判别力验证和一致性验证：good、medium、bad、adversarial 四档能被区分，同一评估器重复三轮分数完全一致。真实样本部分保留人工标注接口，不伪造人工一致性结果。

## 建议录制参数

- 分辨率：1280 x 720 或 1920 x 1080。
- 时长：控制在 110 秒左右，留 10 秒余量。
- 鼠标操作：少切窗口，优先展示 Demo、报告、结果 CSV 三个画面。
- 视频文件名建议：`finsignal-hy3-demo.mp4` 或 `finsignal-hy3-demo.gif`。
