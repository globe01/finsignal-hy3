## 轻量抽检小结

- **READY 4 条**：人工观感与规则高分（93.75）一致，输出质量高，N/A 边界声明规范。
- **PARTIAL 3 条**：模型对缺失字段（goodwill / short_borrow）的 N/A 处理**基本正确**（明确标注不可计算），
  但规则在 `na` / `fact` / `sourcing` 上出现**多处疑似 false positive**——把绝对额（亿元）、
  年份数字误读为比率指标，以及把审慎的「需警惕」误判为强结论。因此 PARTIAL 均分 **73.50**
  可能被规则过严惩罚而**低估**。
- **含义**：这进一步印证「规则评分质量快照」是便宜的**红灯拦截**手段，不等于业务正确性；
  它既能抓到真实缺陷（如确有样本把 N/A 当 0），也会误伤合规输出。**D4/D5 主结论必须以独立
  人工金标准为准**，规则快照仅作离线基线参考。

## 对评估器改进的提示（非本次范围，仅记录）

- `na` 检查应按「缺失年份」分别判定，而非对整个窗口一票否决，避免对有效年份的连带误判。
- `fact` 数值解析需区分「绝对额（亿元）」与「比率」量纲，避免 CFO / 非经常性损益被误读为净利率、商誉占比。
- 趋势方向检测需与输出中明确的方向词（降至 / 下滑 / 跃升）对齐，避免反向误判。
- 以上属评估器口径增强，按「最终交付收口、不再重构核心逻辑」的约定，**本次仅记录、不改动核心评分逻辑**。
