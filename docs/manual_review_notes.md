## 轻量抽检小结

- **READY 4 条**：人工观感与规则高分（当前 96.25）一致，输出质量高，N/A 边界声明规范。
- **PARTIAL 3 条**：模型对缺失字段（goodwill / short_borrow）的 N/A 处理**基本正确**（明确标注不可计算），
  早期规则在 `na` / `fact` / `sourcing` 上出现**多处疑似 false positive**——把绝对额（亿元）、
  年份数字误读为比率指标，以及把审慎的「需警惕」误判为强结论。当前已修复主要误伤，PARTIAL 均分提升到 **91.00**。
- **含义**：这进一步印证「规则评分质量快照」是便宜的**红灯拦截**手段，不等于业务正确性；
  它既能抓到真实缺陷（如确有样本把 N/A 当 0），也会误伤合规输出。**D4/D5 主结论必须以独立
  人工金标准为准**，规则快照仅作离线基线参考。

## 对评估器改进的提示（非本次范围，仅记录）

- `na` 检查已扩大 N/A 语义窗口，避免对有效年份金额连带误判。
- `fact` 数值解析已剔除年份和带金额单位的候选数字，减少绝对额/比率混淆。
- 趋势方向检测已改为只看收入/营收所在分句，避免被毛利率回升等后文污染。
- 保留边界：自然语言规则评测仍可能误伤，真实主结论以信号级人工复核为准；当前样本量仍较小。
